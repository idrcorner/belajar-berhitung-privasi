Kebijakan Privasi Belajar Berhitung

Terakhir diperbarui: 27 Oktober 2026

Belajar Berhitung adalah aplikasi latihan berhitung untuk anak TK sampai kelas 4 SD. Aplikasi ini dibuat untuk dipakai anak bersama orang tua.

Data yang disimpan

Aplikasi hanya menyimpan data berikut, dan semuanya tersimpan di perangkat ini saja:

  • nama panggilan anak yang diisi orang tua di menu Profil;
  • pengaturan level dan jenis soal;
  • riwayat latihan: tanggal, soal, jawaban, nilai, dan lama mengerjakan;
  • PIN orang tua untuk membuka menu orang tua, disimpan dalam bentuk hash (bukan angka aslinya);
  • pilihan suara dan getar.

Data yang tidak dikumpulkan

  • Aplikasi tidak memerlukan akun dan tidak meminta email, nomor telepon, lokasi, foto, kontak, atau mikrofon.
  • Aplikasi tidak mengirim data apa pun ke server, tidak memakai iklan, dan tidak memakai layanan analitik atau pelacakan.
  • Aplikasi tidak memerlukan koneksi internet.

Berbagi lembar kerja dan laporan

Orang tua dapat membagikan lembar kerja (gambar atau PDF) dan laporan mingguan lewat menu bagikan Android. File hanya dikirim ke aplikasi yang dipilih orang tua sendiri. Fitur ini berada di menu orang tua yang dilindungi PIN.

File cadangan

Orang tua dapat mengekspor file cadangan (berisi nama panggilan anak, pengaturan, dan riwayat latihan, tanpa PIN) lewat menu bagikan Android, lalu mengimpornya di perangkat lain. File ini hanya dikirim ke tempat yang dipilih orang tua sendiri, misalnya Google Drive. Simpan file ini di tempat yang aman.

Suara

Soal dibacakan memakai mesin text-to-speech bawaan perangkat. Teks soal diproses oleh mesin suara di perangkat tersebut. Bunyi benar dan salah adalah file suara di dalam aplikasi, tanpa internet.

Anak-anak

Aplikasi ini ditujukan untuk anak dan mengikuti kebijakan Families di Google Play. Karena tidak ada data yang dikirim keluar dari perangkat, pengembang tidak pernah menerima data pribadi anak. Aplikasi tidak berisi iklan, tautan ke situs web, maupun pembelian dalam aplikasi. Fitur berbagi dan cadangan hanya ada di menu orang tua yang dilindungi PIN.

Izin Android

Aplikasi tidak meminta izin khusus (tidak ada izin internet, lokasi, kamera, mikrofon, kontak, atau penyimpanan). Memilih file cadangan untuk diimpor memakai pemilih file bawaan Android.

Menghapus data

Data dapat dihapus dengan menghapus profil anak di menu Profil, atau dengan menghapus data aplikasi / mencopot aplikasi dari pengaturan Android.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dimuat di halaman yang sama dengan tanggal pembaruan yang baru.

Kontak

Pertanyaan tentang kebijakan ini dapat dikirim ke pengembang melalui alamat kontak yang tercantum di halaman aplikasi di Google Play.

Belajar Berhitung Privacy Policy

Last updated: October 27, 2026

Belajar Berhitung is a counting practice app for children from kindergarten to grade 4. It is designed to be used by children together with their parents.

Data stored

The app only stores the following data, and all of it stays on this device only:

  • the child's nickname, entered by a parent in the Profile menu;
  • level and question type settings;
  • practice history: date, questions, answers, scores, and time taken;
  • the parent PIN that opens the parent menu, stored as a hash (not the actual digits);
  • sound and vibration preferences.

Data not collected

  • The app does not need an account and does not ask for email, phone number, location, photos, contacts, or microphone access.
  • The app does not send any data to a server, shows no ads, and uses no analytics or tracking services.
  • The app does not need an internet connection.

Sharing worksheets and reports

Parents can share worksheets (image or PDF) and weekly reports through the Android share menu. Files are only sent to the app the parent chooses. This feature is inside the PIN-protected parent menu.

Backup file

Parents can export a backup file (containing the child's nickname, settings, and practice history, without the PIN) through the Android share menu, then import it on another device. The file is only sent where the parent chooses, for example Google Drive. Keep this file somewhere safe.

Sound

Questions are read aloud using the device's built-in text-to-speech engine. The question text is processed by that engine on the device. The correct and incorrect sounds are audio files inside the app and need no internet.

Children

This app is made for children and follows the Google Play Families policy. Because no data leaves the device, the developer never receives any personal data about children. The app contains no ads, no links to websites, and no in-app purchases. Sharing and backup are only available in the PIN-protected parent menu.

Android permissions

The app requests no special permissions (no internet, location, camera, microphone, contacts, or storage permission). Choosing a backup file to import uses Android's built-in file picker.

Deleting data

Data can be deleted by removing a child profile in the Profile menu, or by clearing the app's data / uninstalling the app in Android settings.

Changes to this policy

If this policy changes, the latest version will be posted on the same page with a new "last updated" date.

Contact

Questions about this policy can be sent to the developer through the contact address listed on the app's Google Play page.
